# 总览
## 本地环境与项目搭建
本项目初衷：以最快的方式完成个人网站的搭建，快速部署并上线

前期以静态网站为主，采用极简的 MVP模型

静态网站生成采用Hugo生成器，生成后的项目保存在本地，通过 Git 进行版本控制。随后推送到自己的 Github 账号。

前期首先不购买个人域名，而是使用公网进行部署。技术选型使用 Vercel

改动后的博客内容推送到 Github 仓库，同时将 Github 仓库与 Vercel project 进行 webhook 握手🤝

只要 Github 仓库发生改变，Vercel project 就能第一时间监测到，并通过其域名暴露在公网上。
